# Brew Haven Cafe Website

A modern, responsive website for Brew Haven Cafe featuring a beautiful menu, shopping cart functionality, and user authentication.

## Features

- 🎨 Modern Design
  - Clean and professional layout
  - Responsive design for all devices
  - Dark/Light mode toggle
  - Beautiful food images and animations

- 🛒 Shopping Experience
  - Interactive menu with categories
  - Add to cart functionality
  - Shopping cart with quantity controls
  - Checkout process

- 👤 User Features
  - Login/Register system
  - Social media login options
  - User-friendly navigation
  - Smooth scrolling

- 📱 Responsive Design
  - Mobile-first approach
  - Hamburger menu for mobile devices
  - Optimized images and layouts
  - Touch-friendly interactions

## Pages

1. Home Page (index.html)
   - Hero section with call-to-action
   - About section
   - Contact information
   - Social media links

2. Menu Page (menu.html)
   - Categorized menu items
   - Food images and descriptions
   - Price display
   - Add to cart functionality

## Technologies Used

- HTML5
- CSS3 (with CSS Variables for theming)
- JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts
- Unsplash Images

## Setup Instructions

1. Clone or download the repository
2. Open index.html in your web browser
3. Navigate through the website using the menu
4. Test the shopping cart and authentication features
